# LightFrame AI — Railway + Wan 2.7 VideoEdit

هذه النسخة تصلح خطأ 404 الناتج عن استخدام نموذج `cjwbw/controlvideo` غير المتاح بهذا المسار.

## GitHub
ضع هذه الملفات مباشرة في Root:
- index.html
- server.js
- package.json
- README.md

## Railway
Build Command: `npm install`
Start Command: `npm start`
Root Directory: اتركه فارغًا إذا كانت الملفات في Root.

Variable:
`REPLICATE_API_TOKEN` = التوكن الخاص بك.

## الاستخدام
ارفع MP4 أو MOV أو WebM، ويفضل فيديو من 2 إلى 10 ثوانٍ، ثم اكتب التعديل واضغط زر تعديل الفيديو.
